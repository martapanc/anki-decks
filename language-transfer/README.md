# Language Transfer decks

Study material (lesson summaries + Anki-ready vocabulary CSVs) extracted from
[Language Transfer](https://www.languagetransfer.org) course transcripts.

Each language lives in its own folder with its own README:

- **[`spanish/`](spanish/)** — *Complete Spanish* (90 tracks), grouped into 9 thematic parts.
- **[`french/`](french/)** — *Introduction to French* (40 tracks), grouped into 5 thematic parts.
- **[`italian/`](italian/)** — *Introduction to Italian* (45 tracks), grouped into 5 thematic parts.

CSV rows are `English,<target language>` (English prompt first), standard-quoted so they
import straight into Anki. See each folder's README for the group breakdown.
